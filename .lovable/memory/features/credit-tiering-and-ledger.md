# Credit Tiering & Bi-Monthly Ledger

## Schema
- `companies.payment_terms` text NOT NULL DEFAULT `'prepaid'` CHECK in (`prepaid`,`credit`). Backfill: `allow_credit=true` → `'credit'`. `credit_limit` numeric preserved.
- `bi_monthly_ledgers` (company_id, period_start, period_end, total_amount, order_count, pdf_url, status: draft|sent|matched|disputed|resolved, whatsapp_message_id, generated_at, sent_at). RLS: staff full; buyers read own company.
- `ledger_disputes` (ledger_id, company_id, raised_via, description, status: open|investigating|resolved, resolution_notes, resolved_by, resolved_at). RLS: staff full; buyers read+insert own company.

## Order Confirmation Branching
`OrderManagement.handleAction` — when transitioning `submitted → confirmed`:
- If company `payment_terms = 'credit'` → status jumps to `in_production`, sends "Thank You" WA via `send-whatsapp` invoke.
- If `payment_terms = 'prepaid'` → status moves to `awaiting_advance`, sends manual UPI/NEFT/RTGS instruction WA. Razorpay auto-link is the future plug-in point in this same branch.

## Edge Function: `generate-bi-monthly-ledger`
- Input: `{ company_id?, period_start?, period_end? }`. Empty body = run for ALL credit clients, last 15 days.
- Aggregates orders, builds A4 PDF via `pdf-lib` (champagne accents, soft tone), uploads to `final-invoices/ledgers/{company_id}/...`, inserts `bi_monthly_ledgers` row.
- Sends document via Click2API WhatsApp; falls back to text+link if document send fails. Stores `whatsapp_message_id` on the ledger row.
- `verify_jwt = false`. Listed in `supabase/config.toml`.

## pg_cron
- `bi-monthly-ledger-1st` cron `30 3 1 * *` (09:00 IST on 1st).
- `bi-monthly-ledger-16th` cron `30 3 16 * *` (09:00 IST on 16th).
- Both POST `{}` to the edge function with anon-key Authorization header.

## AdminFinance UI
- New 7th tab "Ledger & Disputes" (`BookOpen` icon) renders `<LedgerDisputesPanel/>` from `src/components/admin/LedgerDisputesPanel.tsx`.
- Panel shows: Generate All button, per-credit-client Generate Now cards, Open Disputes inbox with Resolve modal (notes required), Recent Ledgers table with PDF download.

## WhatsApp Dispute Detection
`whatsapp-webhook` extension (after buffer insert): if inbound text contains `request correction`, `ledger dispute`, `ledger correction`, `account mismatch`, or is exactly `dispute(d)`, the function:
1. Looks up company by phone (last 10 digits).
2. Finds the most recent `bi_monthly_ledgers` row for that company.
3. Inserts a `ledger_disputes` row, marks the parent ledger `disputed`.
4. Sends a soft acknowledgement WA to the sender.
